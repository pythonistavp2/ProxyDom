## Что это

ProxyDom запускает дома два локальных прокси и управляет ими из трея, панели и с локального сайта:

| Часть | Что делает | Порт |
|---|---|---|
| `1-telegram-mtproxy.py` | Ускорение Telegram через WebSocket-мост (на базе TG WS Proxy) | 1443 |
| `2-dpi-proxy.py` | Обход DPI для YouTube / Discord в браузере (фрагментация TLS, без WinDivert и DNS) | 8888 |
| `0-start-all-tray.py` | Запускает оба, сидит в трее, панель с консолями и настройками, локальный сайт | 8899 (сайт) |

Голос Discord (UDP) через DPI-прокси не идёт — это ограничение метода, текст и видео идут.
Для голоса нужен классический zapret с WinDivert (см. оригинальную сборку выше).

## Быстрый старт (ПК, Windows)

1. Установи Python 3.10+ с [python.org](https://www.python.org/) (при установке поставь галку **Add to PATH**).
2. Положи все файлы в одну папку **без кириллицы и пробелов**, например `C:\dom-proxy`:
   `0-start-all-tray.py`, `1-telegram-mtproxy.py`, `2-dpi-proxy.py`, `README.md`.
3. Запусти:
   ```bat
   python 0-start-all-tray.py
   ```
   Откроется обычное окно — **его можно закрыть в любой момент без последствий**,
   прокси живут в фоне под иконкой в трее.
4. При первом запуске разреши Python в брандмауэре Windows, иначе телефон не достучится.
5. Двойной клик по иконке в трее — **панель**: живые консоли обоих прокси и настройки
   (порты, задержка, автозапуск). Панель тоже закрывается без последствий.

## Подключение телефона (тот же Wi-Fi!)

Телефон и ПК должны быть **в одной Wi-Fi сети**. IP ПК подскажет окно запуска, трей или сайт.

- **Telegram:** Настройки → Данные и память → Прокси → MTProto:
  сервер = IP ПК, порт `1443`, secret из окна запуска (сохраняется в `secret.txt`).
  Либо открой на телефоне локальный сайт (ниже) и нажми «Открыть в Telegram».
- **Браузер / YouTube / Discord:** в настройках Wi-Fi сети поставь прокси вручную:
  сервер = IP ПК, порт `8888`.

## Локальный сайт

После запуска открой в браузере (с телефона — в том же Wi-Fi):

```text
http://IP-ПК:8899
```

На сайте: статус обоих прокси, подключение телефона одной кнопкой,
перезапуск/остановка, настройки, живые логи. Порт сайта меняется
(`--web-port`, `0` — выключить). Сайт виден **только внутри твоей домашней сети**.

## Трей, фон, автозапуск

```bat
python 0-start-all-tray.py --background       :: тихо, только иконка в трее
python 0-start-all-tray.py --install-autostart :: автозапуск Windows (тихо, из трея)
python 0-start-all-tray.py --remove-autostart  :: убрать автозапуск
```

То же самое переключается пунктами меню в трее и галкой в панели.
Настройки хранятся в `settings.json`, secret Telegram — в `secret.txt`
(не удаляй его, иначе secret сменится). Логи — в папке `logs/`.

## Частые проблемы

- **Телефон не подключается** — проверь, что он в том же Wi-Fi, и что Python разрешён
  в брандмауэре Windows. Порты по умолчанию: `1443`, `8888`, `8899`.
- **Порт занят** — значит уже запущена вторая копия. Закрой её или смени порты в панели.
- **Крякозябры/краш консоли** — в сборке принудительно включён UTF-8 вывод,
  на старых консолях текст может выглядеть странно, но падать не будет.
- **YouTube долго стартует** — первый запуск идёт через fallback с QUIC на TCP, дальше нормально.
- **Не работает голос Discord** — см. ограничение выше, это не баг сборки.
